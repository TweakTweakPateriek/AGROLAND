# Agroland - Werken aan groei

Website gebaseerd op het aangeleverde InDesign-ontwerp.

## Pagina's

- Home
- Wie is Agroland?
- Wat we doen
- Fotogalerij
- Contact

De fotogalerij beweegt horizontaal. Open een foto voor de schermvullende weergave en gebruik de pijltjestoetsen of knoppen om door de foto's te bladeren.

De website is statische HTML, CSS en JavaScript. GitHub Pages wordt ingesteld om de bestanden vanuit de hoofdmap te publiceren.
